Sobre o Projeto

O Mini Paint Recursion é uma aplicação web que simula uma ferramenta de desenho com pixels, onde o usuário pode criar pequenas artes em uma grade. O destaque do projeto é o uso do algoritmo de Flood Fill (preenchimento por inundação) implementado de forma recursiva, que permite preencher áreas inteiras com uma cor, similar à ferramenta de balde de tinta.

O projeto foi desenvolvido como trabalho da disciplina de Algoritmos e Estruturas de Dados no curso de Tecnologia em Sistemas para Internet (TSI) do IFPE.
